## Qué no se pudo verificar completamente

1. La web interactiva `https://open.geelark.com/api` y `https://open.geelark.com/rpa` devolvió páginas sin texto legible. Para API se encontró el repositorio oficial S13; para RPA se contrastaron S08/S09, notas y el ejemplo GAL. Sigue pendiente el catálogo completo de bloques y sus formularios.
2. El enlace de índice Release notes desde el centro de ayuda devolvió 404. Las páginas v4.5.0/1/2 sí fueron consultables. No se afirma que v4.5.2 sea la última versión.
3. Logs y Referral no explican sus campos en el texto accesible. S19 y S30 permiten verificar algunos eventos y View Task; no todos los filtros ni la retención.
4. Las páginas AIGC recientes y antiguas publican cifras/precondiciones diferentes. Se registra la dependencia de servicios con cargo; no se fija una tarifa comercial como requisito del clon.
5. La captura permite inventariar entradas y botones legibles. Los iconos sin texto y el menú de tres puntos requieren tooltip o diálogo antes de asignarles funciones. No se infieren columnas de una tabla vacía.
6. No hay inspección autenticada de todos los diálogos, permisos, errores, traducciones y estados. La cobertura documental amplia no se llamará clon exacto validado.

## Cómo cerrar una laguna sin frenar el resto

Registrar pantalla/acción pendiente con ID, abrirla en una sesión autorizada cuando toque ese módulo, anotar campos y resultado, y actualizar el requisito antes de programarlo. Las capturas se solicitarán de una en una solo si las fuentes públicas no resuelven el detalle. No pedirlas todas ahora ni repetir pruebas de nuestra plataforma ya aceptadas.
