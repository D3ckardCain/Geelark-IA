Reglas de seguridad visibles

  • La autorización del nodo no se deduce de su salud.
  • Heartbeat ausente, antiguo o con desfase de reloj no se considera saludable.
  • Un módulo no reportado no aparece como operativo.
  • Los errores del servicio no se sustituyen por datos de muestra.
  • La pantalla no ejecuta tareas ni cambia estados.
